# FlyRank Frontend AI Capstone

> Frontend AI Engineering capstone project for the FlyRank internship program.

## Overview

This repository contains the capstone deliverable for the **FlyRank Frontend AI Engineering** internship. The project applies modern frontend development practices and AI-assisted engineering workflows to build scalable, maintainable web applications.

## Tech Stack

| Category          | Technologies   |
| ----------------- | -------------- |
| Language          | JavaScript     |
| Runtime           | Node.js        |
| Version Control   | Git, GitHub    |
| Development Tools | VS Code        |

## Development Conventions

- Use clear and descriptive variable names
- Write clean, readable, and maintainable code
- Follow [Conventional Commits](https://www.conventionalcommits.org/) for Git commits
- Keep functions small and focused
- Add comments only when they improve understanding
